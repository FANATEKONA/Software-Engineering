# Smart Campus Room Availability Checker — Assignment #04

A frontend-only React + TypeScript demo with a fictional four-room catalog, capacity/equipment filtering, and room-specific availability checks. No database, backend, authentication, or real booking operations.

## Setup and run

Requires Node.js and npm. From the `project/` directory:

```sh
npm ci
npm run dev
```

Open the local URL displayed by Vite.

## Test and build

```sh
npm test
npm run typecheck
npm run lint
npm run build
npm run preview
```

`npm test` runs the permanent Vitest test suite, including React Testing Library integration tests in jsdom. The suite defines 42 tests. A real-browser responsiveness check is separate from jsdom tests.

The `dist/` folder is generated by `npm run build` and intentionally excluded from this source archive because the Bolt downloadable ZIP retained an outdated build despite a reported successful workspace rebuild. Build from source to produce the current production bundle.

## Structure

- `src/App.tsx`: UI coordination, filter/selection/time state and result clearing
- `src/types/room.ts`: room and booking types
- `src/data/demoData.ts`: fictional four-room catalog and fixed demo time
- `src/lib/roomFilter.ts`: capacity/equipment filter logic
- `src/lib/availability.ts`: availability validation and structured result
- `src/lib/availabilityMessage.ts`: presentation messages for results
- `src/lib/time.ts`: time conversions and interval handling
- `src/components/`: focused UI components
- `src/test/`: unit and App integration tests
- `baseline/assignment-03/src/`: preserved initial single-room version
- `baseline/task-02/src/`: preserved version before Task #03 refactoring

## Limitations

Uses fictional static data and a fixed demo clock; it checks availability only and does not create bookings. No end-to-end real-browser automation or production API is included.
